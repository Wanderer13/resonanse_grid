# Resonance Grid

Логический пазл на сетке: игрок **ищет резонанс по башням**, а не заполняет цифры и не считает объекты.

На поле расставляются башни трёх частот — `1`, `2` и `3`. Каждая башня шлёт волну по строке и столбцу. Задача — восстановить сеть так, чтобы числа по краям совпали. Эти числа показывают не сумму сигналов и не количество башен, а **резонанс**: совпадение частот у башен, которые видят друг друга.

## Зачем так

В судоку ищут цифры. В сапёре — бомбы. В Train Tracks — путь. Здесь нужно понять **отношения** между башнями: кто с кем резонирует, а кто даёт только шум.

Волны на поле видны всегда. После хода видно, что именно изменилось в сети.

## Как найти резонанс

Две башни взаимодействуют, если между ними по строке или столбцу нет другой башни и нет стены.

- Одинаковая частота — **резонанс** `◎`. В подсказку линии добавляется эта частота: `1 + 1 → 1`, `2 + 2 → 2`, `3 + 3 → 3`.
- Разная частота — **шум** `×`. Вспышка есть, в число он не входит.
- Стена обрывает луч: `1 → ■ → X`.

Числа сверху относятся к столбцам, слева — к строкам. Зелёная подсказка уже совпала с текущей сетью.

Пример: на одной линии стоят две двойки без преграды. Это один резонанс силы `2`. Если на той же линии добавить единицу так, что она «видит» двойку, появится шум, но число линии от шума не вырастет.

Победа — когда **все** краевые числа совпали. Расположение башен при этом можно восстановить логикой: какие частоты вообще способны дать такое число, где луч обязан быть разорван стеной, где две башни должны смотреть друг на друга.

## Как играть

1. Клик по клетке циклит состояние: пусто → `1` → `2` → `3` → пусто.
2. Стены заданы уровнем и не меняются.
3. **Проверить** подсвечивает несовпавшие числа.
4. **Подсказка** открывает одну клетку из решения и фиксирует её.
5. Когда сеть собрана, появляется **Продолжить**. Сначала можно посмотреть волны на готовом поле, затем перейти дальше.

В этом репозитории — web-прототип миров 1–2: обычные башни и стены. Поля от 4×4 до 8×8, двенадцать уровней.

## Запуск

Откройте [`index.html`](index.html) в браузере или поднимите локальный сервер из папки проекта:

```bash
python -m http.server 8766
```

Затем откройте [http://127.0.0.1:8766/](http://127.0.0.1:8766/).
